# 一期工作进度

## 已实现

- React 聊天工作区：会话创建、切换、重命名、删除，模型选择，消息历史与停止生成。
- POST SSE：`message`、`delta`、`complete`、`error`、`cancelled` 事件和 UTF-8 流解析。
- Spring Boot 会话与聊天 API，稳定错误码和请求 ID。
- Spring AI `ChatClient` Agent 适配、OpenAI 兼容配置和内置 Mock 模型。
- MyBatis + MySQL 持久化、Flyway V1 迁移和服务启动恢复。
- Caffeine 最近 20 条已完成消息缓存，数据库回源和删除失效。
- 会话级单生成任务注册和 Reactor subscription 取消。
- Docker Compose 本地部署、Nginx SSE 反代、环境变量模板和冒烟脚本。

## 验证

- 后端 `mvn -DskipTests package`。
- 前端 `npm run build`。
- 前端 Vitest SSE 解析测试。
- MySQL 集成测试依赖本地 Docker daemon；Docker 未运行时跳过，启动 Docker 后执行 `mvn test`。
