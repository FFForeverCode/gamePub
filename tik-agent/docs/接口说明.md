# tik-agent 一期接口说明

接口前缀为 `/api/v1`。普通响应使用 JSON，错误格式为：

```json
{
  "code": "CONVERSATION_NOT_FOUND",
  "message": "会话不存在",
  "requestId": "5f..."
}
```

## 模型

```http
GET /api/v1/models
```

```json
[
  {
    "id": "mock",
    "displayName": "本地 Mock",
    "provider": "mock",
    "defaultModel": true
  }
]
```

## 会话

创建会话：

```bash
curl -X POST http://localhost:8080/api/v1/conversations
```

查询列表：

```http
GET /api/v1/conversations?limit=30&beforeId=100
```

重命名：

```bash
curl -X PATCH http://localhost:8080/api/v1/conversations/1 \
  -H 'Content-Type: application/json' \
  -d '{"title":"一期验收"}'
```

查询消息和删除会话：

```http
GET    /api/v1/conversations/1/messages
DELETE /api/v1/conversations/1
```

## SSE 流式聊天

```bash
curl -N -X POST http://localhost:8080/api/v1/conversations/1/messages/stream \
  -H 'Content-Type: application/json' \
  -H 'Accept: text/event-stream' \
  -d '{"content":"介绍一下这个项目","modelId":"mock"}'
```

事件协议：

```text
id: 1
event: message
data: {"userMessage":{...},"assistantMessage":{...}}

id: 2
event: delta
data: {"messageId":2,"content":"这是"}

id: 3
event: complete
data: {"message":{...}}
```

| 事件 | 含义 |
| --- | --- |
| `message` | 用户消息和空的 STREAMING 助手消息已持久化 |
| `delta` | 一段增量回答，只追加到对应助手消息 |
| `complete` | 完整回答已一次性落库 |
| `error` | 模型失败，包含稳定错误码 |
| `cancelled` | 客户端断开或停止生成 |

同一会话已有生成任务时返回 HTTP `409 GENERATION_IN_PROGRESS`。不可用模型返回 `503 MODEL_NOT_AVAILABLE`。一期不支持 SSE 断线续传，刷新页面后应重新查询历史消息。
